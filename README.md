# k8s-homelab-gitops
GitOps for my Proxmox homelab (pve02). Kubernetes + Argo CD manage core apps and VMs: nginxLoadbalancer, todolist, debianMSSQLServer006 (SQL Server), octopus2025.3.14287 (Octopus Deploy), ollama.webui (Ollama/Open WebUI), and a Win 10 VM. Traefik, MetalLB, Longhorn, monitoring, Grafana &amp; Prometheus.
